## 一、核心结论

1. **价格不是障碍。** 主流独立索引 API 集中在 **$1–15 / 1,000 次查询**（≈¥0.007–0.11/次），中位数约 **$5–7/1k**（≈¥0.036–0.05/次）。一个日均 200 次搜索的 Agent，月成本 **$30–42（¥216–302）**；最低档（Parallel Turbo $1/1k）月成本不到 **¥45**。
2. **真正的差异在「计费机制」而不是「单价」。** 同样标价 $5/1k，可能是「每次调用固定扣」，也可能是「模型自己决定搜几次、每次另计」（模型内置）、「扣 credit 且会过期」（Serper）、或「调用费 + 检索内容 token 双计费」（OpenAI / Anthropic）。选型时必须看机制，不是看单价。
3. **2025–2027 三条供给线在消失。** Bing Search API 已于 **2025-08-11 退役**（只剩 Azure Grounding，且官方明确「输出不得用于其他应用」）；Google Custom Search JSON API 已对新客户关闭、据多方报 **2027-01 关停**；「转卖 Google SERP」的代抓厂商（Serper / SerpApi）是当前唯一能拿到「与 Google 一致结果」的路径，但属法律灰色地带。长期稳定的只剩**独立索引**（Brave / Kagi / Exa / Parallel）与**云厂商第一方**。
4. **对「自建 CDP 抓 Google」的架构，临界点约 2,000–3,000 次/月。** 低于它，自建（现金零成本）划算；高于它，一次封禁/一次改版的人力成本就超过全年 API 费用。**建议：API 为主、CDP 为兜底**，而不是二选一。

## 六、覆盖率与索引规模（关键数字）

**先纠正一个直觉：覆盖率不是「索引了多少页」，而是「索引了哪些页」。**

| 指标 | 数字 | 来源 |
|---|---|---|
| Google vs Bing top-1 重叠 | **31%**（整体重叠始终 <32%；Bing vs DuckDuckGo 15%） | Yagci et al. 2022（学术） |
| AI 助手引用进入 Google Top10 的比例 | 平均 **12%**；**80%** 的引用页面在 Google 上完全没有排名 | Ahrefs 2025（15,000 prompts） |
| 分助手 | Perplexity 28.6% / Copilot 8.6% / Gemini 8.0% / ChatGPT 6.1% | 同上 |
| 搜索质量分（同模型同框架，仅替换搜索供应商） | **Parallel 75 / Exa 74 / Firecrawl 73**；无搜索基线仅 33；已测厂商落在 65–75 | Artificial Analysis Search Index（2026 起，DeepSearchQA / BrowseComp / AA-Omniscience 等权） |
| 全球市场份额 | Google 91.02% / Bing 4.55% / Yandex 1.01% | StatCounter 2025-08 → 2026-08 |

**索引规模（厂商自报口径，规模 ≠ 覆盖）**

| 引擎 | 规模 | 口径 |
|---|---|---|
| Google | ~300B 页（区间示意） | 官方只写「hundreds of billions / well over 100,000,000 gigabytes」，从不给精确页数 |
| Brave | **40B 页** | 官方博客 2026-02（2025-08 时点自报 30B） |
| AWS AgentCore | 数十亿（tens of billions） | AWS 官方博客 2026-06，Amazon 自营索引 |
| Bing | 8–14B | 第三方估算（微软从未公布） |
| Mojeek | 9B | 官方 about 时间线（2015 年 1B） |
| Common Crawl | 2.10B 页 / 单次月度抓取 | 2026-06 快照（354 TiB） |

**对选型的三个含义**

1. **覆盖率只能靠组合，不能靠单选。** 用两家不同来源的索引（如 Brave 自有索引 + 一家 Google 系），重叠低，组合后召回显著高于任何单一引擎。
2. **「索引规模」是最弱的指标。** Brave 40B 与 Mojeek 9B 差 4 倍，但两者与 Google 重叠都远低于 50%——规模差异 ≠ 覆盖差异，要测的是「对你的查询集的命中率」。
3. **中文/非英语是另一条轴。** Google、Brave、Mojeek 对中文长尾覆盖都弱于百度系；国内厂商价值在中文内容与合规。

**如何自测（可复现探针方法）**：准备 30–50 个「已知答案页面」（收藏夹 / sitemap / 近一周新页），为每页写一条**不含域名**的查询，逐家 API 跑同一批，统计 **recall@10 / recall@50 / MRR**；再以 Google 为基线算**互补率**（其他引擎独有命中 ÷ 总命中）——互补率比覆盖率更能指导选型。

## 九、计费陷阱清单（来自官网原文）

1. **模型内置：一次提问可能扣 N 次搜索费。** Gemini 官方定价页原文：「客户向 Gemini 提交的请求可能会触发一次或多次 Google 搜索查询。每执行一次搜索查询，系统都会单独计费。」→ 必须自行设 `max_searches` / 预算闸门。
2. **调用费 + 内容 token 双计费。** OpenAI：「$10.00 / 1k calls + Search content tokens billed at model rates」；非推理 preview 则是 $25/1k 且内容 token 免费——同一家两套规则。Anthropic 同为 $10/1k + token。
3. **credit 会过期。** Serper 采用 credit 池、有有效期（第三方一致称 6 个月）；买多了等于负债。Tavily / Firecrawl 的 credit 也需确认过期策略。
4. **「每千次」计数口径不一致。** Perplexity 按「成功请求」计、多查询单请求只算一次；Tavily advanced 扣 2 credits；Firecrawl search 是「2 credits / 10 条结果」。比较前必须先统一口径。
5. **云厂商的 QPS 规格与阶梯绑定。** 阿里云默认 30 QPS，升档需提前一周申请、连续 5 天不达量会降档——「用不起的量级也拿不到低价」。腾讯/火山为版本制或日结，欠费会停服/释放资源。
6. **Azure Grounding 的输出不能外用。** 官方原文：Outputs are not directly accessible for use in other applications or programs. → 想拿原始链接喂自己的 Agent，这条路直接排除。
7. **代抓 SERP 的供给正在消失。** Bing Search API 2025-08-11 退役；Google Custom Search JSON API 已对新客户关闭、据多方报 2027-01 关停。剩余代抓厂商的法律与断供风险需计入。
8. **按页接口的「缓存免费」要单独确认。** You.com Contents 明确「Pages served from cache are free」；这类条款会显著改变实际成本，务必读原文而不是看标价。

## 十、选型建议（决策矩阵）

**价格带的四个观察**

- **价格收敛在 $5/1k。** Brave、Perplexity Search、You.com、Tavily 订阅档、Exa Answer、Parallel Basic 全部落在这一档。差异化不在价格，而在索引质量、延迟、吞吐上限、是否 ZDR。
- **抽取（读正文）比搜索便宜一个数量级。** Contents / Extract 普遍 $1/1k 页（Exa、You.com）、$4/1k（Kagi）、$0.83–3.2/1k（Firecrawl 按档位）——把预算花在「搜得准」，而不是「抓得多」。
- **云厂商在国内并不便宜。** 火山 ¥20/千次、腾讯轻量 ¥18/千次、阿里极速版 ¥12/千次，折算 $1.67–2.78/1k——比 Brave 便宜，但比 Serper 贵 3–9 倍，且要走 QPS 报备/阶梯/日结。国内价的价值在合规、可用性、中文覆盖。
- **模型内置是最贵的一档，且成本不可预测。** OpenAI $10–25/1k + 内容 token；Anthropic $10/1k + token；Gemini $14/1k query 且一次提问可能多次计费。（例外：Gemini 官方写明「通过接地功能检索到的上下文不计入 input token 费用」。）

**落地建议：保持接口语义不变，下层做可插拔 SearchProvider**

| 层 | 建议选择 |
|---|---|
| 主路 | **Brave**（日常搜索，$5/1k、50 QPS、ZDR）或 **Parallel Turbo**（$1/1k、~200ms） |

## 附录 A：法律风险（美国）摘要

**问题**：以「人类方式驱动真实浏览器」（不黑入、不破坏防御、不自动过验证码、不绕登录墙）是否招致更多美国法律诉讼？

**结论**：没有找到任何以「模拟人类操作」本身作为违法事由或判决依据的案件或法规。检索到的所有相关诉讼，诉因都是：**绕过技术措施、违约、转售数据、假账号**——不是输入方式。

**三条风险线（只需要盯这三条）**

1. **合同**：违反 ToS → 禁令 + 赔偿（hiQ 赢了 CFAA 却赔了 $500,000）。
2. **撤销授权后继续**：收到 C&D / 被 IP 封锁后仍继续（尤其换 IP、代理、账号）→ CFAA 成立（Meta v. BrandTotal、Facebook v. Power Ventures、Craigslist v. 3Taps）。
3. **规避技术保护措施**：绕 CAPTCHA / 限流 / 登录墙 / 付费墙 → CFAA + DMCA §1201（票务场景另加 BOTS Act）。

**关键判例**

| 判例 | 结论 |
|---|---|
| Amazon v. Perplexity（第九巡回，2026-08） | ✅ 撤销对 Perplexity 的初步禁令：CFAA 下的「访问者」是**用户**，不是代理厂商（限缩于当前记录） |
| Van Buren v. United States（最高法院，2021） | ✅ 违反 ToS 本身不构成 CFAA 违法 |
| Meta v. Bright Data / X Corp v. Bright Data（2024） | ✅ 抓取公开数据主张被驳回；browsewrap ToS 效力弱 |
| hiQ v. LinkedIn（第九巡回） | ⚠️ 双刃：CFAA 赢、合同输（$500,000 + 永久禁令 + 删除数据与算法） |
| Ticketmaster v. Prestige（第九巡回，2020） | ⛔ 用 bot + CAPTCHA 农场绕过安全措施 = 明确红线 |
| Google v. SerpApi（N.D. Cal.，2025-12 起诉） | 🎯 唯一直接针对「抓 Google 搜索」的诉讼：核心指控是**反规避 + 转售**，不是人类化操作（2026-07 DMCA §1201 部分驳回，诉讼继续） |
| Ryanair v. Booking.com（第三巡回，未决） | ⚖️ 当前最大不确定性：若维持，将削弱第九巡回的 hiQ 路线 |

**一句话总结**：架构越像「用户自己的浏览器」，越安全；越像「一个后台云服务替所有人抓」，越危险。Comet 赢在「请求从用户浏览器发出」，SerpApi 被诉输在「转售」。

> ⚠️ 免责声明：本节不是法律意见，不构成律师-客户关系。所有结论来自公开判例与成文法（截至 2026-09-17），个案仍在进行（Google v. SerpApi、第三巡回 Ryanair）；具体情形请咨询美国执业律师。
